project alpha

Go Networking CLI

overview

a lightweight reverse proxy and tunnel tool written in pure go. exposes local http/tcp services to the public internet without port forwarding or complex nat traversal setups.

usage

# clone & run
git clone https://github.com/notand1mo/project-alpha
go run main.go --port 8080

features

• single static binary with zero runtime dependencies
• automatic tls termination with letsencrypt support
• persistent multiplexed websocket / tcp fallback
